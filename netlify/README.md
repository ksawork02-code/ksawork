# 넷리파이 주소 페이지 (앱스크립트 웹앱 감싸기)

앱스크립트 웹앱을 짧은 주소로 열어 주는 페이지입니다. 기능은 모두 앱스크립트에서 동작하고, 이 사이트는 주소만 제공합니다.

| 주소 | 열리는 화면 |
|---|---|
| `https://<사이트>.netlify.app/` (또는 `/login`) | 관리자·컨설턴트 로그인 |
| `/apply` | 기업 컨설팅 신청폼 |
| `/pre` | 차년도 사전접수 폼 |
| `/consultant` | 컨설턴트 신청폼 |
| `/status` | 기업 신청 진행조회 (접수번호 + 사업자번호) |
| `/survey?t=…` | 만족도 설문 (앱이 보내는 메일 링크) |

## 배포 (5분)

1. **웹앱 주소 넣기**: `config.js`를 메모장으로 열어 `WEBAPP_URL`에 앱스크립트 **배포 → 배포 관리**의 웹 앱 URL(`…/exec`)을 붙여넣고 저장합니다.
2. **올리기**: https://app.netlify.com/drop 에 접속해 이 폴더(`netlify`)를 통째로 끌어다 놓습니다. 넷리파이 계정이 없으면 무료로 가입합니다.
3. **주소 정하기**: 넷리파이 **Site configuration → Change site name**에서 `ksa-consulting`처럼 원하는 이름으로 바꿉니다. 그러면 주소가 `https://ksa-consulting.netlify.app`이 됩니다.
4. **앱에 알려 주기**: 앱 관리자 화면 **설정** 탭의 `PUBLIC_URL`에 넷리파이 주소를 넣고 저장합니다. 이제 메일 링크와 "배포 링크"가 넷리파이 주소(`/apply` 등)로 바뀝니다.

나중에 `config.js`를 고쳤다면, 넷리파이 사이트의 **Deploys** 화면에 폴더를 다시 끌어다 놓으면 됩니다.

### 기관 도메인을 쓰려면 (선택)

넷리파이 **Domain management → Add a domain**에서 `consulting.ksa.or.kr` 같은 주소를 추가하고, 기관 전산팀에 안내되는 CNAME 레코드를 등록해 달라고 요청합니다. HTTPS 인증서는 넷리파이가 자동으로 발급합니다.

## 알아 둘 점

- 앱스크립트 코드를 새 버전으로 배포해도 웹 앱 URL은 그대로이므로 넷리파이는 다시 배포할 필요가 없습니다.
- 화면이 열리지 않으면 15초 뒤 "새 창에서 열기" 링크가 나타납니다. 회사 보안 프로그램이 다른 사이트 안에 넣은 화면을 막는 경우에 대비한 것입니다.
- 아이폰 사파리는 다른 사이트 안에 넣은 화면의 저장 공간을 제한합니다. 그래서 넷리파이 주소로 접속하면 30일 로그인 유지가 더 짧아질 수 있습니다. 컨설턴트가 로그인이 자주 풀린다고 하면 로그인 화면만 웹앱 주소로 직접 안내하세요.
